# Mini Figma

Мини-редактор векторных фигур в браузере: React + TypeScript + Tailwind CSS.

## Запуск

```bash
npm install     # один раз
npm run dev     # dev-сервер на http://localhost:5173
```

## Управление

- **Пробел + мышь** — панорамирование холста
- **Колесо мыши** — зум 10%…400%
- **R / O / V** — инструменты: прямоугольник / эллипс / выбор (работает на любой раскладке)
- **Мышь** — перетащите фигуру, чтобы переместить (весь драг — один шаг истории)
- **Панель слоёв** — клик по слою выделяет фигуру на канвасе
- **Ctrl+Z / Ctrl+Shift+Z** — отмена / повтор действий (история до 100 шагов)

## Архитектура

```
src/
├── types/         # Единый язык проекта: Shape, Tool, координаты
├── constants/     # Инструменты, клавиши, подписи
├── utils/         # Чистая математика: экранные <-> канвасные координаты
├── hooks/         # Логика без интерфейса: камера, фигуры, хоткеи
└── components/    # Интерфейс: Canvas, Shape, Toolbar, панели
```
